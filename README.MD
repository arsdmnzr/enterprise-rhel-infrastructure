Enterprise RHEL Infrastructure Lab

Designed and implemented a production-style hybrid infrastructure using RHEL 9 integrated with Windows Server 2025 Active Directory. The environment includes a bastion host, Apache web server, MariaDB database server, NFS and Samba file services, Prometheus and Grafana monitoring, centralized rsyslog logging, and automated rsnapshot backups. All Linux servers authenticate directly against Active Directory, demonstrating enterprise identity management, security hardening, monitoring, logging, and disaster recovery practices.
